Один файл `index.html`, без сборки и зависимостей.

- Связь — только Telegram `@Velkro0` (блок «Контакты» внизу страницы).
- Цены в блоке «Услуги» — под ваш рынок.

## Бесплатный хостинг (лучше Render для статики)
Render для статики подходит, но для одного HTML-файла удобнее:

### Вариант 1 — GitHub Pages (самый простой)
1. Создайте репозиторий `ВАШ_НИК.github.io` (публичный).
2. Загрузите `index.html` (Add file → Upload files → Commit).
3. Через минуту сайт откроется по адресу `https://ВАШ_НИК.github.io`.

### Вариант 2 — Cloudflare Pages (быстрее всего в СНГ, бесплатный SSL и CDN)
1. dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git.
2. Выберите репозиторий, Build command оставьте пустым, Output directory — `/`.
3. Каждый push в GitHub обновляет сайт автоматически. Адрес вида `имя.pages.dev`.

### Вариант 3 — Netlify
Перетащите папку с `index.html` на app.netlify.com/drop.

Свой домен `.kz` или `.com` (~5 000–8 000 ₸/год) подключается в любом из вариантов.

## Безопасность GitHub
Статический сайт без паролей и ключей безопасно держать в публичном репозитории.
Не коммитьте: пароли, токены, `.env`, личные документы.
